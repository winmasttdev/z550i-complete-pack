< Flashing or updating phones

This step-by-step guide will show you how to flash your Sony Ericsson phone.

All the files needed are shown throughout the tutorial, but you can also find everything here.

Currently, there is no unified way to flash every Sony Ericsson phone for free, so the flashing instructions differ for every Sony Ericsson platform but they're all relatively easy to execute.

Disclaimer

As with any modification of any kind, there is a small chance your phone will be bricked if something goes wrong. Do this at your own risk!

Identifying SE Platform

0. If your Sony Ericsson phone runs Symbian OS, Windows Mobile or Android you can skip the steps below. Symbian UIQ smartphones can be identified by a loading bar during the boot-up sequence.

1. Take the battery cover off your phone and read your phone's model number

2. Head to this page and see what platform it belongs to. If your phone has Ericsson T28 connector you might also want to check this page
If you have a DB2020 phone, you will also need to check its CID value before flashing it with SEtool LITE.

3. Download firmware for your phone. You can either search it up or download it from these sources:

  • Dumbphone repo
  • firmware.center
  • Google Drive repo for Android-based Xperia phones
  • TopSony archive.

4. Follow the instructions for your phone's platform from this article

Important information about A100/A200 Firmwares

⚠️ Notice that ALL A100/A200 firmwares must have three files (that sometimes can't be found in one source):

  • MAIN file (.mbn/.bin)
  • Filesystem file (.fbn/.bin)
  • Finalization (Customization) Package (usually comes in .zip achives with a filesize less than a megabyte)

If you don't flash ALL firmware files you WILL brick your phone

Customization packages are a collection of files which are used by phone to have different apps/languages/menu appearance pre-installed. They can be Russian/Asian/Central European/etc or even entirely custom made. You can even tinker with them by yourself and make your SE phone, for example, have only arabic language. That leaves you with the ability to use pretty much any customization package, just make sure it's intended for your phone model

Omnius method

Difficulty: ···· Easy

Omnius was a paid flashing utility until it became free in 2024 when it was given to the new owner. Omnius can be downloaded here.

The software is able to flash almost any Sony Ericsson phones starting from A100 platform-based ones including the ODM and Android-based phones, although certain models, most commonly ODMs, need to be flashed through certain cables or boxes. It also supports unlocking (user code reset and network unlock), GDFS/TA backup and writing, and replacing the software security certificate, which can be done via a USB cable for most models.

Please note that Windows Mobile smartphones (except Aspen) and Android smartphones by Sony Mobile are not supported by Omnius, though they were listed in the drop-down menu in the Phone type section.

Prerequisites

- Any Windows PC starting from Windows XP
 - Gordon's Gate Flash Drivers installed on that PC (can be downloaded here)
- A USB cable, such as the standard Sony Ericsson DCU-60 or Sony Ericsson DCU-65 cable for FastPort-equipped phones

Setting up Omnius

Install the program from the installer located in the archive. At the moment account login via Omnius website doesn't work, so you need open a ticket in the Kaijousuru Discord server[1] in order to create an account.

For the first time users, navigate to Server tab and select Server Settings. Input your username and password that was provided to you and click Save changes. Make sure that Access the server via hostname is selected as the connection method. Additionally, you can check your account status by selecting Account Info.

After you've completed all necessary steps, you have set up Omnius successfully and you can go on flashing your Sony Ericsson phone.

Identifying your phone

1. In Actions tab, choose the correct phone model from the drop-down menu in the Phone type section.
2. Click Identify (information icon) in the Actions section. For UIQ and early A1 phones, the Operation Settings windows will be opened, where it suggests you to choose the connection method and the maximum communication speed. By default, the connection method is through the DCU-60/DCU-65 cable and the maximum communication speed is unlimited. Click OK.
3. Connect the phone turned off with the USB cable while holding the "C" key on your phone.
4. Wait for the software to identify your phone. The software will read the phone's internal info such as chipset, CID, certificate color and the info from the GDFS such as the phone model, branding, software info, language package and the locks.

Backing up phone's GDFS

1. In Actions tab, choose the correct phone model from the drop-down menu in the Phone type section.
2. Click Advanced (triangle and cylinder icon) in the Actions section and choose Backup GDFS (Backup TA and GDFS for the later phones starting from A200) from the drop-down menu.
3. The Operation Settings window will be opened, where it suggests you to choose the connection method, output folder for the GDFS and the maximum communication speed. For A200 and later phones, the Advanced settings section suggests you to backup TA (Misc & Normal) and GDFS, but you can do it separately by ticking/unticking the boxes. By default, all the three boxes are ticked.
4. Connect the phone turned off with the USB cable while holding the "C" key on your phone.
5. Wait for the software to back up the GDFS.

Flashing

1. In Actions tab, choose the correct phone model from the drop-down menu in the Phone type section. Additionally, copy the needed firmware files (MAIN, FS and customization pack) into the path for you phone model which is located by default in C:\ProgramData\Omnius for SE\Flashes\*your phone model*.
2. Click Flash (lightning bolt icon) in the Actions section.
3. The Operation Settings window will be opened, where it suggests you to choose the connection method, flash files and customization files. By default, the connection method is through the DCU-60/DCU-65 cable for most of the phones. In the Flash settings section, choose the Main FW and Raw FS files from the path where all the needed firmware files are stored. In the Customization settings section, you can either choose the customization pack in .zip manually from the path, or let the software perform the default customization, choosing the desired customization pack in the drop-down menu of the Perform default customization option. When you're flashing the customization pack manually, choose Do not perform default customization.
4. Connect the phone turned off with the USB cable while holding the "C" key on your phone.
5. Wait a few minutes for the software to flash your phone.

Congratulations! Your phone is flashed!

Unlocking

1. In Actions tab, choose the correct phone model from the drop-down menu in the Phone type section.
2. Click Unlock (keychain t icon) in the Actions section.
3. The Choose an Operation window will be opened, where Omnius suggests you to choose whether to unlock a phone from a network lock by reset, or simply reset a user code back to 0000.
4. If you've chosen the "Unlock network lock by reset" option, the Operation Settings window will be opened, where Omnius suggests you to show unlocking codes for your phone, as well as an option to repair SEMCBOOT and change the certificate color if desired.
4. Connect the phone (which should be turned off) with the USB cable, while holding the "2" and "5" keys on your phone.
5. Omnius will ask you to reconnect the phone a few times, repeat step 4 when Omnius asks you to do so.

Congratulations! Your phone is unlocked!

A100 platform

SEtool2 LITE method | Windows

Difficulty: ···· Easy

This method only works for DB2010/12/20 and won't work for CID53 DB2020 phones
SEtool2 Lite can be downloaded here

Prerequisites

- Any Windows PC newer than Win2K(By the time of writing this article, latest Windows 11 25H2 works)
- Gordon's Gate Flash Drivers installed on that PC (can be downloaded here)
- Standard Sony Ericsson DCU-60 or Sony Ericsson DCU-65 cable
- Disabled Antivirus or a whitelisted SeTool executable in it (Most AVs including stock Windows Defender falsely flags SeTool)

Identifying phone's CID

1. Open SEtool LITE and select "Identify" from the right row of buttons
2. Hold the C Key on your phone and connect it to the PC (SETool also tells this in the console window)
3. Look at your CID on SEtool's log window. If the FLASH CID is not equal to 53 you may continue

Backing up phone's GDFS

You may skip this step but this may come in handy if you somehow brick your phone later on. Even if you won't backup the GDFS it's still pretty easy to restore

0. Disconnect your phone, remove the battery and insert it back if it was connected from the previous steps
1. Select your phone type from the dropdown list, then click "Read GDFS" from the right row of buttons
2. Disconnect your phone, remove the battery and insert it back, click "Ready"(SETool also tells this in the console window)
3. Hold the C Key on your phone and connect it to the PC
4. Wait a few minutes for SEtool to backup your GDFS.

Flashing the phone

0. Disconnect your phone, remove the battery and insert it back if it was connected from the previous steps
1. Select your phone type from the dropdown list, add MAIN and FS files to the "Files" section of the program by clicking "Add", finalization package to the "MISC" section. Click the "FLASH" button afterwards.
2. Hold the C Key on your phone and connect it to the PC (SETool also tells this in the console window)
3. Wait a few minutes for SEtool to flash your phone.

Congratulations! Your phone is flashed and you're awesome!

jdflasher method | Windows

Difficulty: ···· Easy

This method works for any A100 phone.....But you can't backup GDFS with it (importance, or rather lack of it, of backing up your phone's GDFS is explained in the SEtool section)

Prerequisites

- Any Windows PC newer than Win2K(By the time of writing this article, latest Windows 11 25H2 works)
- Gordon's Gate Flash Drivers installed on that PC (can be downloaded here)
- Standard Sony Ericsson DCU-60 or Sony Ericsson DCU-65 cable

jdflasher Installation

You need to download old 32-bit FAR manager for it (official link) and jdflasher plugin for it (official link)

Create a folder jdflasher inside *your FAR installation path*\plugins and put archive contents inside
Open FAR Manager, click F11 on your keyboard and select jdflasher - that's it!

Flashing the phone

1. Open jdflasher interface, select your phone if it's db2010, or the platform itself if it's not under the "script" selection and put the maximum speed possible under the "speed" selection, click "jump down the rabbit hole"
2. Select either the "bflash" or "oflash" (doesn't matter which one)
3. Follow jdflasher's instructions if there are any - Disconnect your phone, remove the battery and insert it back, click ok, connect your phone holding the C Key
4. Find your MAIN and FS files in the inactive FAR manager's window, select one of them with your mouse/keyboard and click F5 on your keyboard. Click "Copy"
5. Wait for jdflasher to finish, then repeat the STEP 4 again with the second file (depending on what you selected before)
5. Wait for jdflasher to finish, select ".." above the "memory" folder and press yes
6. Disconnect your phone, remove the battery and insert it back, and repeat the STEP 1
7. Select either the "bfs" or "ofs" (doesn't matter which one) and follow jdflasher's instructions if there are any
8. Go to the tpa/preset/custom and put finalization files (not the archive!) there by copying them from the inactive window
9. Wait for jdflasher to finish, select ".." button until jdflasher prompts you to exit, and then disconnect your phone
9.1 If you were flashing DB2010 phone and it doesn't boot after, reflash MAIN file once again by following the steps above

Congratulations! Your phone is flashed and you're awesome!

XS++ method | Linux

Difficulty: ···· Medium

This method works for any A100 phone and better overall, but you need to use Linux and install outdated libraries

Prerequisites

- Any Linux debian-based distro
- Standard Sony Ericsson DCU-60 or Sony Ericsson DCU-65 cable

XS++ Installation

This section is incomplete.
Please help us by expanding it.

TL;DR: Find an XS++ 4.1 executable (not available on dumbphone repo), install libfltk 1.1 (you will have to overwrite newer libs if you're using modern distro), give XS++ full permissions with chmod command

XS++ is opened via terminal, you need to run it under root

Backing up phone's GDFS

You may skip this step but this may come in handy if you somehow brick your phone later on. Even if you won't backup the GDFS it's still pretty easy to restore
1. Click "Connect" on the XS++ Main page then connect your phone to the PC holding the C Key
2. Select the GDFS tab, then click "Read GDFS" from the right row of buttons
3. Wait a few minutes for XS++ to backup your GDFS.

Flashing the phone

1. Click "Connect" on the XS++ Main page then connect your phone to the PC holding the C Key
2. Select the Flash Firmware tab, check all checkboxes and select MAIN file under the "Flash Main Firmware", FS file under "Flash File System", Customization archive under the "Select CustPack"
3. Click "FLASH" button and wait a few minutes for XS++ to flash your phone.

Congratulations! Your phone is flashed and you're awesome!

A200 platform

4SE method | Windows

Difficulty: ···· Medium

4SE was a PAID solution but become abandonware a couple of years ago. It was cracked around early 2010s making it one, if not the only tool to flash almost every A2 Sony Ericsson phones With it being cracked software, no links will be provided (you can easily find it on the internet), it is also not available on the Dumbphone Repository.
This software does NOT work on modern Windows and you will have to use either 32-bit versions of Windows XP, Vista or 7.
Combining all factors above, you should probably set up a Virtual Machine to run it, and either make a snapshot or just never turn it off

You MUST run this tool via HWID_Patched executable

Prerequisites

- Windows XP/Vista/7 PC
- Gordon's Gate Flash Drivers installed on that PC (can be downloaded here)
- Standard Sony Ericsson DCU-60 or Sony Ericsson DCU-65 cable

Backing up phone's GDFS

You may skip this step but this may come in handy if you somehow brick your phone later on. Even if you won't backup the GDFS it's still pretty easy to restore

1. Select your phone from the list on the left and choose GDFS/TA tab
2. Click "START" on the bottom right side of the program and connect your phone holding keys 2 and 5
3. Wait a few minutes for 4SE to backup your GDFS.

Flashing the phone

1. Select your phone from the list on the left, choose "Flash" tab and then "Choose firmware files"
2. Choose your MAIN, FS files and a customization archive
3. Click "START" on the bottom right side of the program and connect your phone holding keys 2 and 5
4. Wait a few minutes for 4SE to flash your phone.

Congratulations! Your phone is flashed and you're awesome!

Androxyde Flashtool method

Difficulty: ···· Medium

Androxyde Flashtool is one of three methods used to flash Sony Ericsson Xperia and Sony Xperia phones. Newer versions will have issues with flashing older phones so it is advised to use a older version when possible, no links will be provided but you can easily find older versions on the Internet.

Do note the firmware may also not show up in certain cases, this will also cover how to fix the issue.

Prerequisites

  • a Windows PC (recomended as Linux and macOS versions are broken).
  • a microUSB data cable.

Flashing

  • 1. Start by opening Flashtool and select the "⚡️" icon.
  • 2. Select "..." and locate the folder you placed the .ftf firmware files in.
    • Should the firmware not show up in the menu or the firmware uses seperate files for firmware and custom
      • 1. Start by extracting the .ftf file using 7zip, then select "Tools", then select "Bundle Creation" and point to the folder of the extracted .ftf.
      • 2. Click and drag all of the files and press the "- >" button to move it to the "Firmware content" part.
      • 3. Then select "Device"(do make sure it is the device that is matching like "SK17 SonyEricsson Xperia mini pro") and the variant of said device like SK17i, "Branding" and "Version", this is important.
      • 4. Finally, click "Create" and then wait for the .ftf file to be made.
      • Once it's finished, now you have a .ftf file alongside a .torrent one, the .torrent one is not used for the flashing process.
  • 3. Select "Device", "Version" and "Branding" in the drop down menu.
    • On older versions, just select the file for your device that you are flashing.
    • Optional: Should you decide to wipe the internal storage, go over to the "Wipe" section and click "Data", note that this will delete every data in the internal storage.
  • 4. Select "Flash" and plug your device in while pressing Volume Down or Back key depending on your device and wait for the process to finish.
  • 5. Unplug your device and turn your phone on.

Congratulations! Your phone is flashed and you're awesome!

Omnius for SE — notes only, nothing downloadable was verified

WHAT IT IS
  A general Sony Ericsson flashing/unlocking tool. Free since 2024. Works from the A100
  platform upward, so it covers the Z550i (DB2010). Does flashing, GDFS/TA backup,
  user-code and network unlock, and software-security-certificate replacement.

SETUP NOTES (from lpcwiki, for when you do get it)
  - Windows XP or newer; Gordon's Gate Flash Drivers installed (we have those, see tools/).
  - account login via the Omnius website is currently broken; you must open a ticket in the
    Kaijousuru Discord to get an account.
  - Server tab -> Server Settings -> paste user/pass -> tick "Access the server via hostname" -> Save.
  - Actions tab -> Phone type -> pick the model -> Identify. UIQ / early A1 phones get an
    "Operation Settings" dialog for cable type and speed; use DCU-60/DCUE-65.
  - Connect with the phone OFF, battery out/in, holding C.
  - flashing: put MAIN (.mbn) and Raw FS (.fbn) into
    C:\ProgramData\Omnius for SE\Flashes\<model>\ ; customization pack either selected
    manually ("Do not perform default customization") or let Omnius pick a built-in one.

WHY THIS IS NOT A PROBLEM HERE
  Everything Omnius would do is covered by the files already in this repo:
  XS++ 3.1 (tools/) for official flash + FSX, SETool2 Lite (tools/) for official flash,
  FAR + jdflasher + SEFP2 (tools/far_A1_extract/, plugins/) for break mode, filesystem
  access and .vkp patching. Omnius is a convenience wrapper, not a dependency.

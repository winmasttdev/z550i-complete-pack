WHAT IS WORTH KNOWING ABOUT THE SET
  More than half of it covers other models — A2 phones, W580, DB3350. That is normal: this
  was a general Sony Ericsson modding tutorial dump, and the Z550i-relevant parts are the XS++
  and ElfPack documents. The A2 tutorials are still worth reading for method even though the
  A2 flasher does not work on this A1 phone.

FORMAT
  Old binary .doc files with embedded images, in directories named after the document. Word,
  LibreOffice and most .doc readers open them. They predate .docx by a wide margin, so expect
  2006-era layout and no accessibility metadata.

PAIRED WITH
  ../docs/ for the web documentation, which is better structured and current enough to be
  accurate about CID 49 DB2010.
